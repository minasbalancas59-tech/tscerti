O QUE MUDA
──────────
O bloco ENSAIOS deixa de ser duas colunas lado a lado e passa a
ter duas faixas empilhadas:

  ┌─────────────────────┬─────────────────────┐
  │ SENSIBILIDADE       │ REPETIBILIDADE      │
  ├─────────────────────┴─────────────────────┤
  │ EXCENTRICIDADE (largura inteira)          │
  └───────────────────────────────────────────┘

· A excentricidade tem cinco posições e três diagramas, que
  ficavam apertados em meia página. Os desenhos vão de 150 para
  230 pt e a tabela ganha a largura toda.
· A linha "Referência (pos. 1)" vai de 6,5 para 8 pt.

COMPENSAÇÃO DE ALTURA
─────────────────────
Empilhar duas faixas gasta mais altura que duas colunas lado a
lado. Para não voltar a estourar para a segunda página, parte do
respiro do patch anterior foi devolvida:
      padding da moldura ... 6 -> 5
      espaçamento .......... 4 -> 3
      células .............. 3,5 -> 2,5

Nenhum outro modelo é afetado.


COMANDOS
────────
Suba este .zip para /root/cert-saas pelo FileZilla e rode:

    cd /root/cert-saas
    unzip -o modelo4-faixas.zip
    git apply --check modelo4-faixas.patch
    git apply modelo4-faixas.patch
    git add -A
    git commit -m "Modelo 4: ensaios em duas faixas"
    git push
    ./atualizar.sh --build
    rm -f modelo4-faixas.zip

Não há migration nesta atualização.
(Se o unzip não estiver instalado: apt install unzip -y)
