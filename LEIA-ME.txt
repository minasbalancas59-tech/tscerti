 09/09/2026

O QUE MUDA
──────────
Na página que abre quando alguém escaneia o QR do certificado, o
link "conheça os planos" volta a apontar para a vitrine do próprio
sistema:

  agora no servidor   https://tscerti.totalscale.com.br?origem=qr
  volta para          https://certificados.totalscale.com.br/tscert.html?origem=qr

Um arquivo só: src/Api/wwwroot/validar.html


⚠ ATENÇÃO — OS OUTROS DOIS LINKS
─────────────────────────────────
O mesmo endereço tscerti.totalscale.com.br também foi colocado em:

  · index.html   — os dois links da TELA DE LOGIN
  · portal.html  — o link no PORTAL DO CLIENTE

Se o endereço ainda não serve a página de planos, esses dois também
estão levando a lugar nenhum. Este patch NÃO mexe neles — me avise
se quiser que voltem também.


COMANDOS
────────
    cd /root/cert-saas
    unzip -o volta-link-validar.zip
    git apply --check volta-link-validar.patch
    git apply volta-link-validar.patch
    git add -A
    git commit -m "Pagina de validacao do QR: volta a apontar para a vitrine"
    git push
    ./atualizar.sh --build
    rm -f volta-link-validar.zip

Não há migration.


COMO CONFERIR
─────────────
Abra a página de validação de qualquer certificado emitido
(está no rodapé do PDF, ou escaneie o QR) e clique em
"conheça os planos": deve abrir a vitrine do sistema.
