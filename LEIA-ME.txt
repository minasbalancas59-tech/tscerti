 CORRIGE "USO DO DIA" TRAVADO EM "CARREGANDO…"
 05/09/2026
════════════════════════════════════════════════════════════════

O PROBLEMA
──────────
A tela abria e ficava parada em "Carregando…", sem erro na tela.

CAUSA
─────
A coluna jsonb com a lista de usuários chega como STRING pelo
Dapper, não como array. O .map() sobre ela estourava — e como isso
acontecia DEPOIS do try/catch que cobria só a busca na API, a
exceção ia para o console e a tela ficava congelada.

Esse é o pior tipo de falha: não dá nenhuma pista de onde olhar.

O QUE MUDA
──────────
1. Converte a string para array antes de usar (aceitando também
   array puro, caso o mapeamento mude um dia).
2. Envolve a montagem da tela inteira em try/catch, para que
   qualquer falha futura apareça escrita na tela em vez de deixar
   o "Carregando…" eterno.

Só o app.js muda — nada de migration nem de backend.


COMANDOS
────────
    cd /root/cert-saas
    unzip -o fix-uso-dia-carregando.zip
    git apply --check fix-uso-dia-carregando.patch
    git apply fix-uso-dia-carregando.patch
