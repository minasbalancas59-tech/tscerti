 HISTÓRICO DO CLIENTE — ABRIR PENDENTES COM UM CLIQUE
 01/09/2026
════════════════════════════════════════════════════════════════

O QUE MUDA
──────────
No cadastro do cliente, em "Histórico de calibrações", os
certificados em rascunho e aguardando aprovação já apareciam na
lista, mas não eram clicáveis — só os emitidos. Para continuar um
ensaio ou aprovar um pendente era preciso voltar ao painel e
procurar na lista.

Agora cada linha abre no lugar certo:

    rascunho ................ ✏️ Continuar
                              abre o ensaio para seguir preenchendo

    aguardando aprovação .... ⏳ Revisar e emitir
                              abre a tela de revisão/aprovação

    emitido / substituído ... 📄 PDF
                              (comportamento de sempre)

Reaproveita o abrirCert(), que já faz esse roteamento no painel e
trata o caso de rascunho de outro técnico (perguntando se deseja
corrigir mantendo a autoria ou assumir).


COMANDOS
────────
    cd /root/cert-saas
    unzip -o hist-cliente-clicavel.zip
    git apply --check hist-cliente-clicavel.patch
    git apply hist-cliente-clicavel.patch
    git add -A
    git commit -m "Historico do cliente: abrir rascunhos e pendentes com um clique"
    git push
    ./atualizar.sh --build
    rm -f hist-cliente-clicavel.zip

Não há migration nesta atualização.


COMO CONFERIR
─────────────
Abra um cliente que tenha certificado pendente (a Imperium tem
vários). No histórico, a linha deve mostrar o botão "⏳ Revisar e
emitir" e abrir a tela de aprovação ao clicar.
