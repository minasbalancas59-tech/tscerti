 COBRANÇA — AVISO NA GERAÇÃO + INADIMPLENTES SOB DEMANDA
 09/09/2026
════════════════════════════════════════════════════════════════

DUAS MUDANÇAS, A SEU PEDIDO
────────────────────────────

1. O AVISO DE ATRASO NÃO SAI MAIS SOZINHO

   Antes, toda cobrança vencida e em aberto disparava e-mail
   automático. Como a baixa do pagamento é manual, isso cobraria
   quem já pagou e a baixa ainda não foi lançada.

   Agora: nova aba "💰 Inadimplentes" no painel do super-admin.
   Lista as mensalidades vencidas, com dias de atraso, total geral
   e um botão "Enviar aviso" em cada linha — você decide quando.

   Empresas sem gestor com e-mail cadastrado aparecem destacadas
   (o botão fica desabilitado: não teria para quem mandar).

2. NOVO E-MAIL — "MENSALIDADE DISPONÍVEL"

   Antes, entre a cobrança nascer (dia 1º) e o lembrete de
   vencimento (5 dias antes), o cliente não sabia de nada.

   Agora, no mesmo dia em que a cobrança é gerada, sai um e-mail:
   "a mensalidade de setembro/2026 está disponível, vence em
   10/09/2026", já com o bloco de PIX. Continua saindo também o
   lembrete de 5 dias antes — são dois avisos, não substituem um
   ao outro.

   Cobranças de meses passados NÃO disparam esse aviso
   retroativamente (a migration cuida disso).


ENDPOINTS NOVOS
────────────────
  GET  /api/sa/inadimplentes
  POST /api/sa/inadimplentes/{id}/avisar


COMANDOS

    cd /root/cert-saas

    git apply cobranca-inadimplentes.patch

    docker compose exec -T db psql -U certsaas -d certsaas \
        < db/seed/155_aviso_cobranca_gerada.sql

    git add -A
    git commit -m "Cobranca: aviso na geracao, atraso so manual, tela Inadimplentes"
    git push
    ./atualizar.sh --build
    rm -f cobranca-inadimplentes.zip

⚠ A MIGRATION É OBRIGATÓRIA e vem ANTES do build. Ela cria a coluna
  aviso_gerada_em e marca as cobranças antigas como já avisadas —
  sem isso, a primeira execução do Worker mandaria o e-mail de
  "disponível" para TODAS as cobranças pendentes já existentes,
  inclusive as antigas.


COMO CONFERIR
─────────────
· Painel do super-admin → "💰 Inadimplentes": deve listar as
  mensalidades vencidas, com o botão de envio.

· O e-mail de "disponível" só sai quando uma cobrança nova é
  gerada (dia 1º do mês, ou quando você criar um contrato). Para
  ver sem esperar o mês virar, confira no Mailpit:
      http://127.0.0.1:8025

· Confirme no banco que a coluna existe:
      docker compose exec -T db psql -U certsaas -d certsaas \
        -c "SELECT count(*) FROM cobranca WHERE aviso_gerada_em IS NOT NULL"


SE QUISER RELIGAR O AUTOMÁTICO NO FUTURO
──────────────────────────────────────────
O trecho que enviava o aviso de atraso sozinho foi removido do
Worker, mas continua no histórico do Git (commit anterior a este).
Quando a baixa de pagamento for automatizada, é só recuperar aquele
trecho.
