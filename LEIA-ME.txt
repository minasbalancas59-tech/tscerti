 CORRIGE A TELA "USO DO DIA"
 05/09/2026
════════════════════════════════════════════════════════════════

O ERRO
──────
  GET /api/sa/uso-dia
  42883: function sa_uso_dia(timestamp without time zone)
         does not exist

CAUSA — não é a migration
─────────────────────────
A função existe. O que não bate é o TIPO do parâmetro: o Npgsql
envia DateTime como "timestamp without time zone", e o Postgres não
converte implicitamente para date ao decidir qual função chamar.

Corrigido com cast explícito: sa_uso_dia(@dia::date)

Se a migration 153 ainda não tiver rodado, o erro seria o mesmo —
então confirme, por garantia:

    docker compose exec -T db psql -U certsaas -d certsaas \
      -c "\df sa_uso_dia"

Deve listar a função. Se não listar, rode a migration antes:

    docker compose exec -T db psql -U certsaas -d certsaas \
      < db/seed/153_uso_diario.sql
